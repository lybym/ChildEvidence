ChildEvidence 生产研究知识、教育判断/支持/复盘方法、互动人格与表达规范，通过 DSH 原生插件服务儿童、家长或教师。首阶段低风险；本地科研生产、云端通用资产服务，个人记录由宿主管理。研发与 Issue 创建已获授权。

## 冲突与处理方式

| 事项 | 当前依据 | 规划处理 |
|---|---|---|
| AI 生产成果进入真实使用 | AGENTS #16/#18/#20；KNOWLEDGE_GOVERNANCE §2–§4；当前仍限制未经审核资产发布 | 在专门治理任务比较人工审核路线与明确标记的低风险 AI 审查试用路线，记录决定、资格与证据限制；未决前不放行 |
| 人格由科研生产并可改进 | KNOWLEDGE_GOVERNANCE §2 当前草案写“人格原则不在可变更范围” | 修订为有依据性质、版本、评测与明确发布动作的人格资产；新论文不得直接修改运行中人格 |
| Harness 中立的科研处理 | CE-POL-01 当前登记绑定 Codex 环境；Reviewer 契约请求 Astra | 按真实服务/环境/模型身份管理，不用平台名称泛化授权；#10 模型限定如需调整，先明确变更目标 |
| 通用 Schema 与发布资产 | 旧草案绑定标签成熟度，现有验证器只支持部分 Schema 关键字 | 将技术校验、科学评价、实际审核方式、发布资格、个体适用性分别表达，并保持兼容迁移 |
| 个人记录与不可删除审计 | 科研记录要求保留历史，AGENTS #14 禁止儿童数据入仓库 | 科研审计不套用到儿童记录；宿主提供纠正、删除、保留期限和权限隔离，科研云端不收个人档案 |
| CE-02 人工审核资源 | #2 仍要求真实人工完成 80 项 | 决定继续、缩小或延期，不能用 AI 结果代替人工完成；保留原 Issue 历史 |

## 决策与实施顺序

1. 明确首包用途、实际审核方式、发布资格、人格变更和必要确认；不能只把旧的三方签署改成一个形式化按钮。
2. 将确认后的规则联动更新到四份科研规程、AGENTS、治理契约、Skill 与相关验证器；同版本演进，保留变更理由。
3. 资料处理授权与科研质量分别验收；完成获准最小包接入与预检负向测试。
4. 接续 #10 跑通真实首篇，保留未解决项；独立人工核验未发生就明确记录，不冒充完成。
5. 按最终资格发布真实资产。合成工程演练始终与真实发布隔离。

目前允许整理设计和开发任务；具体允许读入哪些科研内容、是否可用于真实儿童支持，仍须满足对应规则。工程自动化不自动产生科研批准。
