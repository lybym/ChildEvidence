- 实验日期：2026-10-13；运行环境：Windows 11 原生，Python 3.12.14，ASReview 3.0.8

### WSS@95 计算公式（v1 旧口径，已被 §0 v2 修正取代）

WSS@95 = 1 − n95/N；n95 = min{k : cum(k) ≥ ⌈0.95·R⌉}（cum 为筛选顺序上的累计相关数）。
本数据 R=141，需要累计找到 134 条；N=393。
v2 修正：WSS@95 = 0.95 − n95/N；旧口径保留为 `wss@95_unadjusted`。

## 2. 关键发现

1. **主动学习在前 20% 筛选预算内明显优于基线**：Recall@20% 三个 AL 模型 0.31–0.33，
   是 random（0.21）的 ~1.5 倍、tfidf 相似度基线（0.24）的 ~1.35 倍；
   Recall@10% 上 svm_max 0.172 vs random 0.112。
2. **WSS@95 全部偏低（0.07–0.15）**：原因是本库正例占比极高（141/393=36%）且
   "ingested" 集合主题异质，尾部仍散布大量正例 → 达到 95% 召回必须筛选 333–367 条。
   **这不是 ASReview 失效，而是标签定义与库结构的属性**。对 ChildEvidence 更有意义的
   指标是早期精度（Precision@10% 0.55–0.61）与"50% 预算处漏筛数"（见 §3）。
3. **50% 预算处的漏筛风险**：若在第 50 百分位停止筛选，被排入后 50% 的相关文献数
   （**v1 此处误用跨种子并集口径**：svm 59、nb 68、logistic 71 vs random 136、tfidf 127）。
   **逐 run 正确口径见 §0**：svm 42.6±1.8、nb 47.2±2.4、logistic 45.2±2.2 vs
   random 72.4±3.8（理论 70.3）→ AL 相对随机减少约 35–41%。
4. 种子方差可接受（WSS@95 std ≤0.034），结果可复现（固定种子+固定依赖版本）。

## 3. 失败案例与风险（`../results/asreview-errors.jsonl`）

- **中文文献被系统性低估的个案**：nb_max 多个种子中，中文正例被排到 60%–81% 分位
  （如 lt-5a3181335cc9《2~3岁阶段执行功能与母子互动的关系》rank 319/393；
  lt-51d1bfbffaf6 rank 312/393）。跨种子统计：nb_max 后 50% 中含 217 个中文正例命中
  （去重前），中文正例占总数 26/141=18%，但在 bottom-50% 占比明显更高 → 风险确认。
- **经典理论文献漏筛**：bottom-50 中出现 1972 年等老文献（理论/概念类正例）。
- **历史标签偏差放大**：ingested 集本身由同一批标题/摘要驱动产生，模拟中模型学到的
  "相关性"部分是采集管线的关键词偏好（citation_expansion 等标签占 90 条），
  真实专家认为相关但历史被拒的文献会被模型持续压后——必须依赖 A2 人工复核打破
  （`../datasets/asreview-human-review-queue.csv`，80 条，含 54 条历史拒收）。

## 4. Oracle 停止问题（必须声明）

模拟中的 WSS@95 是**事后计算**：真实筛选中无法知道"已达到 95% 召回"。
真实流程需要停止规则（如连续 N 条不相关 + 定期人工抽样）并接受不可验证的残余风险。
本 POC 未验证任何停止规则的有效性。

## 5. 局限

1. 无 Gold Label：全部指标基于历史标签代理，**不能**宣称"真实筛选准确率已验证"。
2. 标签不平衡且正例占比高，WSS@95 口径在此库上天然偏低；跨库比较无意义。
3. 121 条缺失摘要（不虚构补全，置空参与）；这些条目排序质量依赖标题。
4. A2 人工复核未完成（本机无人工标注员）→ 已交付标注任务包，未声称完成。

## 6. 结论（供 FINAL_RECOMMENDATION 引用）

- **建议：只借鉴主动学习算法与工作流，不直接集成 ASReview 全家桶**。
  依据：① AL 排序增益真实且计算成本极低（单次 <2s）；② 但 WSS@95 的价值在本库
  正例占比下失真，需要更合理的早期精度/漏筛口径；③ ASReview 的项目管理（Flask/项目文件）
  与 ChildEvidence 的 SQLite 事实源模型重叠度高，直接集成会引入第二套状态管理；
  ④ 标签必须由人工复核流程供血（A2），否则模型只会复现历史偏差。
- 建议下一阶段：以 `nb+tfidf+max`（ELAS u3）作为排序器嵌入现有筛选界面，
  每批 10 条推给人工；用 A2 的 80 条复核结果先校准代理标签质量，再谈部署。
