# appraise

参考 RESEARCH_METHODOLOGY §8.2、§10（DRAFT v1.1）。需要获准原文或可追溯的解析文本；只有元数据/摘要时不得完成方法学质量评价。先识别设计，再核对人群、年龄、样本、地区、测量、对照/随机化（如适用）、失访、混杂、统计方法、报告偏倚和适用边界；理论文献不强套 RCT 指标。

把设计与局限写入 `assessments.appraisal` 的草稿，分开记录已定位事实与待核实疑问。既有规程没有量化打分表，不能自行创造总分、正式质量等级或新的纳入规则。引用量/声望不是质量。严重偏倚、无法判断、儿童诊断/医疗干预/明显风险建议均 unresolved；质量差不推出 not_relevant。

每条事实用 findings 并引用 supporting_sources；缺失项 null，解释未决原因。正式 appraisal 等级仍是人工审核职责。本次未获准把原文送云端时，仅作 blocked/unresolved 的元数据演示。
